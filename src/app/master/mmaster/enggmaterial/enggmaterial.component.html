Material Code — Coding Pattern

The material code is generated automatically when a new material is saved. It is built from four parts:

Plant + T + SUB + 0001
Part Meaning Source
Plant Plant code prefix Configured per plant.
T Material Group/Type code (1 letter) M = Engg Store Mech, E = Engg Store Elect, S = Stationary, H = Housekeeping, C = Canteen, B = Building Material, D = Machine Spares (Dedicated), N = Machine Spares (Common), Q = QC Materials, I = IT Materials, O = Others
SUB Sub Group/Type short code The Short Code defined for the selected Sub Group/Type.
0001 Running serial number (4 digits) Auto-incremented, generated on save.
Example
  • MD + S + PB + 0001 = MDSPB0001 — Stationary / Paper Bond

Note: Grade is not part of the general / engineering material code.
