Material Code — Coding Pattern

The material code is generated automatically when you save. It is built from four parts:

XX + Y + Z + 0001
Part Meaning Source
XX Material Type code (2 digits) 10 = Raw Material, 20 = Packing Material, 30 = General Material, 40 = Engineering Spares, 50 = Equipments
Y Grade code(s) The code defined in Grade Master for each selected grade. Multiple grades are joined together (e.g. two grades → YY).
Z Source Type code (1 digit) 1 = Imported, 2 = Local, 3 = Local/Imported
0001 Running serial number (4 digits) Auto-incremented per pattern, generated on save.
Examples
  • 10 + A + 2 + 0001 = 10A20001 — single grade
  • 10 + AB + 2 + 0001 = 10AB20001 — two grades selected

Note: every selected grade must have a code configured in Grade Master, otherwise the code cannot be generated.
