1. Big picture

MRP answers three questions in order:

  1. What do we need to make? (customer FO/PO → work order)
  2. Do we have the materials? (stock check → buy if short)
  3. When and on which line? (process plan → verify → book → approve)
flowchart TD
  start([Start: Customer need]) --> marketing[Marketing creates FO or PO]
  marketing --> approve[FO/PO approved]
  approve --> receive[Planning receives FO/PO]
  receive --> genWO[Generate Work Order]
  genWO --> stockCheck{Materials enough?}
  stockCheck -->|Yes| processPlan[Process Plan]
  stockCheck -->|No| shortage[Shortage Analysis]
  shortage --> buy[Confirm Indent then Purchase]
  buy --> stockIn[Material received GRN]
  stockIn --> processPlan
  processPlan --> verify[Verify stock]
  verify --> book[Line booking]
  book --> lineAppr[Line approval]
  lineAppr --> nextStages([Then QA Batch / Production / Dispensing])

4. When stock is short

flowchart LR
  A[WO needs material] --> B[Shortage found]
  B --> C[Manager approves shortage]
  C --> D[Indent raised]
  D --> E[Indent confirmed]
  E --> F[Optional Lock]
  F --> G[Purchase buys]
  G --> H[Goods received]
  H --> I[Back to Process Plan]
Remember: Indent cannot be raised until shortage is Approved (submitter cannot approve their own request). A Locked indent needs unlock-with-reason or cancel before silent changes. Cancelling an indent updates the shortage picture automatically.

5. Immediate vs Future

ClassMeaningWhat to do
ImmediateNeeded within ~30 days (or overdue)Priority for Process Plan → Verify → Book
FutureNeeded later than 30 daysKeep visible; plan when closer
Not DecidedNo clear date yetSet date or choose class on Process Plan

6. Line booking history

Every create or change to a line booking keeps a version. Older versions are not erased — useful for audits.

flowchart TD
  B1[Book line - Version 1] --> B2[Change - Version 2]
  B2 --> B3[Change - Version 3]
  B3 --> Now[Current booking on screen]
  B1 -.-> Hist[History keeps all versions]
  B2 -.-> Hist
  B3 -.-> Hist

7. Dashboard KPIs and Trace

On the Planning / STP dashboard:

  • See KPI chips: Immediate WOs, Locked indents, Pending shortage approvals, Booking versions, Cancel recalcs.
  • Enter a Work Order and/or Material code → click Trace to see the full stage timeline.
flowchart LR
  W1[Work order] --> W2[Immediate]
  W2 --> W3[Line booked]
  W3 --> W4[History versions]
        
flowchart LR
  S1[Shortage submitted] --> S2[Indent confirmed]
  S2 --> S3[Indent locked]
  S3 --> S4[Or cancelled with recalc]

8. Stock popup (what the numbers mean)

BucketMeaning
Store availablePhysically usable stock
ReservedAlready committed to other WOs
Under testQC not released — not free stock
Open PO / TransitOrdered or in transit — not in hand
Open indentIndent sent; PO/GRN not finished
Net shortageStill short after the above

Open PO, transit, and open indent help planning, but they are not physical store stock.

9. Forecast vs Confirmed

DemandMeaning
ForecastPlanning / forecast signal (e.g. billing “Forcast”)
ConfirmedFirm order (e.g. “PO for Billing”)

Both can enter Planning. Confirmed is firmer for execution; Forecast still drives material visibility.

10. Training checklist

  1. Marketing FO/PO approved?
  2. Planning received it (Forecast or Confirmed shown)?
  3. Work order generated?
  4. If short → Stock popup → Shortage approved → Indent raised?
  5. Indent confirmed (locked if required)?
  6. Process Plan: Can Plan / Immediate or Future?
  7. Verify → Line book → Line approve?
  8. Optional: Trace on dashboard for that WO/material — last stage looks right?
